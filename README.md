
# Expense Tracker Lambda POC

This project demonstrates how to manage an existing AWS Lambda function
using AWS SAM, CloudFormation, CodeBuild and CodePipeline.

## Configuration

- Runtime: Node.js 22.x
- Handler: index.handler
- Architecture: x86_64
- Deployment: AWS SAM

## Source Code

The Lambda handler is located in:

src/index.mjs

## Build

npm run build
